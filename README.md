# postgres_backup

## Установка:

```
curl -o ~/backup.sh https://raw.githubusercontent.com/potesuch/postgres_backup/main/backup.sh && chmod +x ~/backup.sh && ~/backup.sh
```

## Команды:

- `pg-backup` — быстрый доступ в меню из любой точки системы
- `pg-backup backup` — сделать бэкап вручную
- `pg-backup restore` — восстановить бэкап
